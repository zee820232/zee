# Zee 工程八条第一性原理

1. **事实胜于推理**：路径、符号、配置与报错一律以真实读取和命令输出为准，关键结论标注 `[实测]` 或 `[推断]`，绝不编造。
2. **最小必要上下文**：先定位再精确读行段；按需加载对应 `playbooks/*.md` 与 `roles/*.md`，拒绝无关常驻税。
3. **减法优先与边界归属**：先看能否删代码、合抽象再做加法；数据在边界一次性解析收敛，每份核心状态保持唯一 Owner。
4. **变更最小闭环**：每次改码立刻跑最窄构建/测试，小步绿灯推进，不攒大改盲赌。
5. **测外部行为，拒绝假通过**：只测可观测契约（拒绝锁死内部实现的同义反复废测，**负向测试须配正向测试验证链路接通**）；禁 `@ts-ignore`/`as any`/`eslint-disable` 凑绿，收尾必跑 `gate-tamper-diff`。
6. **跨家族实证对抗**：高危、0→1 或过夜产出由异构 `adversary`（`reviewer`/`judge`）只读实证审查；无执行/调用链证据的猜想一律丢弃。
7. **两败质疑前提**：同一故障连败 2 次立即停损复盘并质疑前提假设本身，写入 `decisions.tsv` / `state.json`；遇 429/5xx 自动熔断切备。
8. **经验固化进结构**：重复犯错按「架构 → 类型/Lint → 测试 → 文档」逐级下沉环境固化，**机械拦截落地后即删旧文字规则**，绝不靠堆长提示词祈祷。
