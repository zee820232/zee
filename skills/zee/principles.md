# Zee 工程六条第一性原理

1. **事实胜于推理**：文件路径、符号名、配置与报错一律以真实读取和命令输出为准，禁止凭记忆编造；行不通立刻报错定位，不粉饰太平。
2. **最小必要上下文**：先检索定位再读精确行段；只按任务按需读取对应的 `playbooks/*.md` 与 `roles/*.md`，不把无关文档塞进上下文。
3. **变更最小闭环**：每次代码修改后立即跑最窄相关构建/测试；宁可小步绿灯推进，不一次性大改后祈祷能跑。
4. **拒绝伪造通过**：严禁通过 `@ts-ignore`、`@ts-expect-error`、`as any`、`eslint-disable`、跳过测试或删除断言来凑绿灯；收尾必跑 `gate-tamper-diff`。
5. **跨家族独立对抗**：高风险变更、0→1 主体或过夜产出，须由与作者 `authorFamily` 不同的 `adversary` 在只读沙盒中审查，并附行号证据。
6. **两败即停损与降级**：同一故障尝试 2 次未解立即停下复盘，在总线 `decisions.tsv` / `state.json` 记录原因与断点；遇到通道 429/5xx 自动记录冷却并切换备用或 `inherit`，绝不死循环。
